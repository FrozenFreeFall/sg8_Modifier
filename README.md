# 三国群英传8 · 武将批量转入

Windows 单机战役存档修改器，使用 Python 3.10 及以上版本和标准库。可按姓名或武将编号搜索，把不同搜索结果中的武将加入同一名单。

## 使用方法

1. 双击 `启动修改器.cmd`。也可以在本目录运行 `python -B sg8_editor.py`。
2. 点「打开存档」，选择 `SG8_数字.bytes`。Steam 默认存档目录为 `%USERPROFILE%\AppData\LocalLow\UserJoy\SG8\Save` 下的账号目录。带 `t` 后缀的是配套的槽位信息文件。
3. 用「全选」或「反选」选中当前筛选结果，也可以按住 `Ctrl` 或 `Shift` 多选。点「加入所选」将可转入的武将放进名单，并选择目标据点。还可以用「勾选可转入名将」从整个存档批量加入名将。「转入时拉满」默认勾选，保存时会同时将待转入武将的等级和战技拉满。
4. 选中武将后点「武将拉满」，把该武将的等级升至 99，所有已学战技升至各自上限，并为升到满级后开放的空战技槽装备对应战技。勾选「仅显示我方势力」可查看本方武将，点击「名将」表头可将名将排在当前列表最前面。同一个武将可以同时加入转入和拉满名单。
5. 退出游戏后点「备份并保存」，确认后将改动写入原槽位。同目录的 `SG8_数字.bytes.<时间>.bak` 是完整的原存档备份。也可以点「导出修改副本」，在指定目录中生成同名存档和可用的槽位信息文件。取消「转入时拉满」时，武将转入仍会自动写入 99 级所需的经验。
6. 进入游戏，读取对应槽位，在武将列表中查看结果。要恢复备份，退出游戏，把 `.bak` 文件复制回原目录，并用它替换同名的 `SG8_数字.bytes`。

工具会尝试从 Steam 安装目录读取中文姓名、名将标记和战技数据。需要手动载入时，点「选择游戏资源」，指定游戏目录 `SG8_Data\resources.assets`。关闭「仅显示可转入」即可看到暂不可转入的武将及原因。

列表中的等级按存档经验和游戏等级表计算。当前体力取自战役存档，基础武力和基础智力取自游戏武将配置或可识别的自建武将记录。游戏内面板还会计入成长、装备和称号等加成。点击这三项的列标题可按数值升序排列，再点一次切换为降序。

魔吕布（2986）和神赵云（2987）即使位于特殊据点，也可以在存档显示为在野且无军团、任务或事件引用时搜索并转入。

## 据点与势力

打开战役存档后，点「据点与势力」。可选择单个或全部我方据点，填写要设定的农业、商业、技术、民怨、城防和预备兵力，再点「加入据点修改」。输入框下方显示编辑范围。下限为 0，民怨上限为 100，其余上限依据游戏资源中的据点规模和对应配置。选择全部据点时，以各据点中最低的上限为准。空白项沿用存档数值。

- 「钱粮拉满」把我方势力的金钱和粮草都设为 `999,999,999`。
- 「传说装备各99件」把本机资源中识别到的传说武器、坐骑和饰品各设为 99 件，国库里缺少的装备会补入。
- 「史诗装备各99件」对本机资源中的史诗武器、坐骑和饰品应用同样的数量设置。
- 「兵种训练拉满」写入当前剧本各兵种的满级训练经验，例如工兵 25 级、投石车 30 级、龙牙石车 35 级。游戏内的征募及补兵按来源据点的归属和规模判断。

返回主窗口后，点「备份并保存」或「导出修改副本」应用这些设置，可以与武将修改一起保存。

## 兵种来源与配兵

点主窗口的「兵种来源与配兵」，可查询每种兵的来源据点和所需规模。要配置兵种，先勾选「仅显示我方势力」，选中武将，再打开配兵窗口核对完整名单并点「配给选中的武将」。配置保留原有兵力，0 兵力的武将需补兵后出战。修改随存档一起保存。

## 验证范围

以本机 Steam 战役存档和徐晃招募前后的两个测试槽为依据。原据点失去最后一名驻城武将时可能转为无主。若批次会让原势力失去最后一座城池，工具会拦截保存。正在出征、仍被任务引用或有特殊身份的武将可能需要先在游戏中处理。

可在本目录运行 `python -B -m unittest -v`，检查格式读写、批量转入和备份行为。游戏官方的单人招募说明见 [凤凰游戏官网](https://sg8.fhyx.hk/news/210207/561.html)。
